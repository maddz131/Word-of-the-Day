# Word-of-the-Day
Experimenting with python and the Merriam-Webster Dictionary API to generate a random word and it's definition.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Create a `.env` file in the project root with your API key:
   ```
   DICTIONARY_API_KEY=your_api_key_here
   ```
   
   Get your free API key from: https://dictionaryapi.com/register/index

3. Run the program:
   ```bash
   python dict.py
   ```
